# Obsidian Scholar Bridge 0.8.3

为 Zotero 9 和 Obsidian 1.12 设计的本地科研阅读桥接插件。

## 工作流

```text
Zotero PDF
  ├─ 划词
  │    → 提取原句和页码
  │    → 在独立论文 AI 抽屉中预览词典
  │    → 人工确认后保存
  │    → 按 lemma 查找已有词条
  │    → 匹配/补充义项
  │    → Obsidian/Vocabulary/<lemma>.md
  │
  └─ 独立论文 AI 工作台提问
       → 快速 / 深度 / 全文阅读
       → 回读原文和页码复核
       → Obsidian/Literature/<年份 - 论文短标题（稳定索引）>/
```

## 0.8.3 词典操作状态澄清

- 保存、检查恢复、格式更新和关闭预览使用不同且明确的按钮文案。
- 状态卡区分等待确认、正在执行、保存完成、恢复完成、无需执行和失败。
- 首次创建词条不再误报为“恢复”；文件本来完整时明确显示“无需执行写入”。
- 成功完成后的按钮改为不可重复点击的完成状态，避免误以为仍需再次操作。

## 0.8.2 词典操作按钮常驻

- 词典正文继续在独立区域内滚动。
- “确认保存/检查恢复到 Obsidian”和“关闭预览”移到正文滚动框之外并始终可见。
- 无论词典释义、专业搭配和例句多长，都不需要滚动到内容末尾才能保存。

## 0.8.1 操作状态与词典预览优化

- 全文记忆信息卡明确显示未构建、已构建、PDF 变化和旧版记忆状态。
- 已有全文记忆时，重新构建前明确提示会再次提交全文并消耗 Token。
- 提问、会话保存和清空按钮根据当前状态显示实际动作。
- 词典预览与论文问答各自使用独立状态栏，不再显示另一标签的操作消息。
- 词典工作台切换后自动适配内容高度，减少大面积空白；所有义项默认完整展开并通过滚动查看。

## 0.8.0 词典学习、Token 与恢复优化

- 词典预览区支持独立纵向滚动，长释义、专业搭配和多义项不再受窗口高度限制。
- 词典、专业固定搭配与原句句式分析合并为一次快速模型调用，避免重复发送论文语境。
- 专业固定搭配不再只是中英直译：按领域记录专业含义、适用语境和使用限制，并在预览及 Obsidian 中独立展示。
- 每条论文原句新增核心句式、结构拆解、语法要点和学术表达提示，并写入对应词条的语境记录。
- 同词增量更新改为本地确定性合并：保留稳定义项 ID、已有例句与搭配，只补充新语境或真正的新义项。
- 论文问答的快速/深度检索使用分级字符预算；证据复核只发送草稿实际引用页及邻页，减少重复上下文。
- 若词典 Markdown、隐藏数据、论文会话、索引或全文记忆被外部删除，可通过再次确认保存、保存会话或重建全文记忆恢复。
- 机器词典数据升级到 schema v4；旧版 v2/v3 数据继续可读，并在下次确认时增量升级。

Token 设计与各模式预算见 [TOKEN_POLICY.md](TOKEN_POLICY.md)。

## 0.7.3 OneDrive 与长路径保存修复

- 保存会话前按照完整 Windows 路径预算自动缩短文件名，保留问题开头、创建时间和稳定短码，避免 `.md.tmp` 超出安全路径长度。
- 每次写入前重新创建并验证父目录；遇到 OneDrive 瞬时移动目录时自动重试，最后安全回退为直接写入。
- 清理已关闭 PDF 阅读器留下的失效词典预览视图；PDF 选区弹窗关闭后不再访问失效按钮，避免 `can't access dead object` 中断或误报新预览。
- 不删除、不覆盖其他既有目录；过长的旧会话文件名会在下次保存时改用短文件名并更新索引。

## 0.7.2 极简问答操作

- 回答区高度调节改为无可见图形的透明边缘热区，保留上下拖动能力且不再占用视觉空间。
- 选中问答记录中的文字后右键，可选择“引用到提问框”或“复制选中文字”；未选中文字时不拦截原有右键菜单。
- 删除标题栏“放大”按钮，工作台继续支持拖动位置、拖动边角改变大小、最小化和关闭。

## 0.7.1 回答区高度手柄

- 原有左侧圆点手柄改为回答区下方居中的圆角短横杠，不再与“引用选中文字”按钮混在一起。
- 整条细分隔轨道都可上下拖动；悬停时横杠跟随当前界面皮肤显示强调色。

## 0.7.0 界面与稳定性

- 按钮、标题栏、活动页签、用户消息、引用、词典语境和缩放柄统一使用主题变量。
- 回答区高度柄改为短小的中性点阵，不再出现突兀的整条紫色线。
- 新增 [功能完备性审计](FEATURE_AUDIT.md)，逐项记录需求实现、设计取舍和发布验证边界。

- PDF 选区弹窗新增直接引用能力；选中文字、段落或公式后可一键加入论文问答输入框，无需复制粘贴。

## 0.6.1 修复

- 修复 Zotero 插件沙箱中 KaTeX 无法访问页面 `document`、导致公式回退为红色 LaTeX 源码的问题；现改用与页面无关的 `renderToString` 安全渲染。
- 不再依赖 Zotero PDF 容器不稳定的原生 CSS 缩放：工作台左下角提供独立拖动柄。
- 回答区域提供独立高度拖动条，可以直接上下拖动并记住高度。

## 0.6.0 新增

- 问答记录区域支持“紧凑 / 标准 / 扩展”高度，并可拖动右下角自由调整，不再固定为较短窗口。
- 整个浮动工作台支持“放大 / 还原大小”、自由拖动、缩放和最小化。
- AI 回答在 Zotero 中按 Markdown 排版显示标题、列表、引用、表格和代码块，不再直接显示 `##`、`**` 等原始标记。
- 内置离线 KaTeX 0.16.22，将 `$...$` 和 `$$...$$` 公式直接渲染为数学排版；长公式可以横向滚动。
- 提示模型统一输出 Obsidian 兼容的标准 LaTeX，保存时保留公式源码，使 Obsidian 阅读视图继续正常渲染。
- Obsidian 会话改为“问题 N / AI 回答 N”的清晰分轮结构，每轮设置使用折叠提示块，与回答正文分离。

## 0.5.0 会话能力

- 每轮问答完成后自动保存隐藏草稿，关闭 PDF 或重启 Zotero 后仍可恢复。
- 工作台新增历史会话列表、“继续所选”和“新建会话”；旧版已经发布到 Obsidian 的会话会在首次打开时自动导入历史列表。
- 一个阅读会话对应一个稳定会话 ID；首次发布后继续提问，再次保存会更新同一个 Markdown，不再生成重复快照。
- 每条回答分别记录阅读策略、服务商、实际模型、时间和引用页码；同一会话可以混用 Flash 与 Pro。
- 继续历史会话时，在上下文预算内尽量带入早期问答，并始终优先保留最近至少 6 条消息。
- 全文记忆记录 PDF 正文指纹、生成服务商、模型、档位和时间。正文不变时直接复用，正文变化时明确提示并在深度提问时自动更新。
- 切换论文模型时，如果已有全文记忆由另一模型生成，工作台明确提供“仅切换回答模型”和“切换并重建全文记忆”。
- 会话恢复数据保存在 `.scholar-bridge/paper-sessions/`，Obsidian 正文仍保持可读 Markdown。

## 既有功能

- 问答文件改为“首个问题摘要 - 日期时间”，在文件列表中可直接判断内容。
- 论文主页、全文记忆和会话目录分别命名为 `00 - 论文索引.md`、`01 - 全文记忆.md`、`AI 问答记录/`。
- 修复工作台关闭按钮；浮动工作台支持拖动、右下角缩放和最小化。
- 工作台保持在当前 PDF 阅读器内，避免独立窗口造成焦点、主题和状态恢复问题。
- 论文工作台新增独立“论文模型”选择，可在快速模型和深度模型之间逐次切换。
- 阅读策略与模型选择完全分离：快速、深度、全文决定内容读取方式；模型选择决定阅读、汇总、回答和复核实际调用哪个模型。
- DeepSeek 推荐配置下，快速模型对应 `deepseek-v4-flash`，深度模型对应 `deepseek-v4-pro`。
- 词典首次生成、旧词条迁移和增量义项合并全部固定使用快速模型，工作台不提供词典模型切换。
- 词典 Markdown 改为纯阅读版，不再嵌入 JSON、内部 occurrence 标记和其他机器代码。
- 增量合并数据移至 Vault 内隐藏的 `.scholar-bridge/vocabulary/` 目录。
- 删除重复大标题和冗长属性，只保留中文核心释义、英文解释、论文原句、语境、多义项及双语例句。
- 旧词条下次确认更新时自动转为新版排版，原文件备份到隐藏的 `.scholar-bridge/legacy-vocabulary/`。
- 论文 AI 工作台不再注册到 Zotero 原生右侧图标队列，不与附件、标签、关联、翻译等图标混合。
- 工作台改为 PDF 阅读区域中的独立抽屉，可从阅读器顶部按钮或 `工具` 菜单打开并随时关闭。
- 词典预览生成后直接打开当前 PDF 对应的独立抽屉，不会误开其他标签页的面板。
- Zotero `工具` 菜单新增固定的“打开论文 AI 工作台”入口。
- 划词预览生成完成后自动展开工作台并切换到词典页签。
- 工作台发生渲染异常时显示具体错误，不再出现无提示的空白区域。
- 修复 Zotero 9 XUL 项目窗格中只显示标题、正文空白的问题。
- PDF 阅读器顶部新增独立“论文 AI”入口，可一键展开工作台。
- 工作台拆分为“词典预览 / 论文问答”两个页签，词典生成后自动切换到预览页。
- Zotero PDF 划词后先在独立“论文 AI 工作台”预览词典，确认后才写入 Obsidian。
- 预览按“核心解释 → 当前论文原句与语境 → 多义项与例句”展示。
- 兼容 DeepSeek 的异构 JSON 字段，并强制提示模型使用稳定词典结构。
- Obsidian 词条正文只保留可读内容；机器元数据单独保存在隐藏目录，不混入正文。
- 保存真实论文原句、页码、文献身份和 Zotero 回跳链接。
- 词典以 lemma 为中心，不按论文重复创建。
- 每个义项有稳定 `sense_id`；新语境会匹配旧义项，确有新含义时才增加义项。
- 同一句重复点击会在调用大模型前被拦截，避免重复条目和 API 费用。
- 旧版 0.1.0 词条升级时完整保留旧内容。
- 论文问答按“可读标题 + 稳定 key/citekey”建立独立目录和 `00 - 论文索引.md` 主页。
- 每次阅读会话保存到该论文的 `AI 问答记录/`，论文主页自动维护会话索引。
- 支持快速、深度、全文三种阅读模式。
- 深度模式分段阅读全文、建立 `01 - 全文记忆.md`、回读相关原文，并进行第二遍证据审校。
- 全文模式在长度不超过设置上限时向模型提交带页码的完整文本；过长时自动退回深度模式。
- 本地检查回答中的页码是否存在，异常时在回答末尾显示警告。
- 支持 OpenAI Responses API、DeepSeek V4 Flash/Pro、通用 OpenAI-compatible 服务和本地模型。
- API Key 使用 Zotero/Firefox Login Manager 保存，不写入普通首选项。

## 默认模型分工

| 服务商 | 快速模型 | 深度模型 |
| --- | --- | --- |
| OpenAI | `gpt-5.6-luna` | `gpt-5.6-sol` |
| DeepSeek | `deepseek-v4-flash` | `deepseek-v4-pro` |
| 通用/本地 | 用户填写 | 用户填写 |

模型名称都可以修改。插件不会依赖旧的 `deepseek-chat` 或 `deepseek-reasoner`。

## Obsidian 数据结构

```text
Vault/
├─ Vocabulary/
│  ├─ tractable.md
│  ├─ recourse.md
│  └─ aggregation.md
└─ Literature/
   └─ 2026 - A Readable Paper Title (Smith2026)/
      ├─ 00 - 论文索引.md
      ├─ 01 - 全文记忆.md
      └─ AI 问答记录/
         └─ 为什么采用 CVaR - 2026-08-20 14-30-05.md
```

Obsidian 端只接收普通 Markdown，不强制依赖任何社区插件。

用于跨重启恢复会话的 JSON 草稿位于 `.scholar-bridge/paper-sessions/`。这是机器状态目录，不需要在 Obsidian 中阅读或修改。

## 可靠性边界

- `01 - 全文记忆.md` 是全文导航和结构理解层，不能替代论文原文。
- 深度模式会再次回读原文并复核，但大模型仍可能误解复杂公式或表格。
- 本地页码检查可以发现不存在的页码，但无法从形式上证明每个论断都完全被原文支持。
- 扫描 PDF 必须先 OCR。
- 同一页同一词多次出现时，目前选择第一个匹配句并显示人工核对警告。
- 深度模式首次运行会产生多次 API 请求；后续复用本地 `01 - 全文记忆.md`。

## 与现有插件的边界

- 已安装的 Translate for Zotero 继续负责翻译；本插件只追加独立按钮。
- 跨论文知识库 RAG、图表识别和复杂 Agent 工作流可以后续与 llm-for-zotero 等工具配合。
- 本插件的数据层始终保持普通 Markdown，避免被某个第三方插件锁定。

## 第三方组件

- Zotero 工作台的公式渲染使用 KaTeX 0.16.22（MIT License），运行文件和许可证随 XPI 离线提供。
